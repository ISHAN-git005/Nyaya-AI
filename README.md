# Nyaya AI: Indian Legal Intelligence System

Nyaya AI is an NLP-powered legal web application built for the Indian legal framework. It automates statutory legal consultation, contract risk profiling, extractive document summarization, and notice drafting.

## Features
- **Statutory Retrieval:** TF-IDF cosine matching against Indian penal frameworks (BNS, IPC, CrPC, IT Act, NI Act).
- **Legal Notice Generator:** Instant drafts for Cheque Dishonour (Sec 138 NI Act), Dues Recovery, and Tenant Evictions.
- **Contract Risk Scanner:** Detects unilateral termination, unbounded indemnities, and jurisdiction traps.
- **Dual Persistence:** MongoDB default with zero-configuration fallback to TinyDB.
